Đồng Bộ Dữ Liệu Trực Tuyến Nhiều Thiết Bị (Cloud Sync)

Kết nối cơ sở dữ liệu đám mây (Firebase Realtime Database / REST JSON) để điện thoại của HLV và máy tính của Admin tự động đồng bộ tức thì.

Chưa kết nối Cloud

Dán link Firebase Realtime Database của CLB vào đây trên cả máy Admin và máy HLV để dùng chung dữ liệu.

Khi bật, mọi thao tác lưu trên thiết bị này sẽ tự động đẩy lên Cloud và tự động kiểm tra bản mới mỗi 30 giây.

Hướng dẫn tạo link Cloud Database miễn phí trong 1 phút (Google Firebase):

  1. Truy cập console.firebase.google.com ➔ Bấm Create a project để tạo dự án mới.
  2. Ở menu bên trái, chọn Build ➔ Realtime Database ➔ Bấm Create Database ➔ Chọn Start in test mode.
  3. Copy đường link URL hiện ra (dạng https://ten-du-an-default-rtdb.firebaseio.com) rồi dán vào ô trên và bấm Lưu & Kết Nối Cloud!
